# cf-vendor-merge

Skill для агентов (Claude Code, Codex, Cursor): обновление доработанной типовой конфигурации 1С:Предприятие 8.3 на новый релиз поставщика через трёхстороннее git-слияние XML-выгрузок — старый типовой релиз, текущая конфигурация и новый типовой релиз.

Что делает:

- выгружает CF-файлы релизов через `ibcmd` и раскладывает выгрузки по веткам git;
- сливает их и автоматически разбирает конфликты: удаление и изменение объектов, структурное слияние XML, макеты;
- переносит доработки BSL параллельными агентами;
- проверяет результат:
  - ссылки на отсутствующие объекты и реквизиты, права ролей;
  - наши объекты, переименованные в `Удалить*`;
  - импорт в пустую базу;
  - синтаксический контроль модулей платформой (`/CheckModules`), в том числе вместе с расширениями;
  - совместимость расширений: заимствования, перехватчики, вызовы общих модулей, базовые формы, ссылки заимствованных форм.

Информационную базу skill не обновляет: базу обновляют отдельно и только по явной команде.

## Установка

Скопируйте каталог `cf-vendor-merge` в каталог skills агента, например `.claude/skills/` или `.agents/skills/`. Порядок работы описан в `SKILL.md`, грабли и способы их обойти — в `references/gotchas.md`.

## Требования

Только свои скрипты: внешние MCP-серверы и другие skills не нужны.


- Python 3 и `lxml`, git.
- Платформа 1С 8.3 (`ibcmd.exe`, `1cv8.exe`).
- Полные CF-файлы старого и нового релиза (файлы обновления `.cfu` не подходят).
- 25+ ГБ свободного места, каталог для временных баз вне облачной папки.
